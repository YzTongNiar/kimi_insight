优化优先级

P Attention ChunkKdaFwd / FusedInferAttentionScore检查 KDA/Attention 的融合、KV 与中间张量读写、布局转换及 MTE 利用率。
P 通信与 MoE all-gather / reduce-scatter / GroupedMatmul检查通信消息量、拓扑、token 路由和通信计算重叠。
D MoE GroupedMatmulSituQuant / Dispatch / Combine针对小 token batch 优化 tiling、量化融合、搬运和专家负载均衡。
D Attention FlashMlaWithKvcache / RecurrentKda检查 KV cache layout、单 token 访存合并、向量化和同步开销。
